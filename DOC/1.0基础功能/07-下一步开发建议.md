# AnythingLLM 批量导入工具(Android 版)— 下一步开发建议

> 编制日期:2026-09-11 | 状态:供下步开发决策使用
> 说明:基于 04–06 文档的遗留项、已知边界与过程经验,给出按优先级排序的开发建议;每项含背景、影响、建议方案、工作量估算。

---

## 1. 遗留未决项(优先级最高)

### N1 真机回归 R11
- **背景**:回归清单 R11(真机连局域网 IP 端到端)未执行,交付底线为"模拟器验证"。
- **影响**:局域网真实网络、存储权限、省电策略、屏幕适配均未在真机确认。
- **建议**:拿到一台 Android 8.0+ 真机后,按 R1–R10 全量复测一遍(重点:局域网 IP 连接、大文件、深色模式、日志导出)。
- **工作量**:约 0.5–1 人日。

### N2 全拒绝时"下一步"按钮显式禁用
- **背景**:用例 F 验证:100MB+1 与空文件等全拒绝时,点"下一步"无推进(行为正确),但按钮未置灰。
- **影响**:体验歧义(用户可能以为卡死)。
- **建议**:预校验结果 `通过数==0` 时设置 `enabled=false` 并给出提示文案。
- **工作量**:约 0.1 人日。

## 2. 已知边界与加固建议

### N3 替换阶段(update-embeddings deletes / remove-documents)无重试
- **背景**:FR-08 只要求上传重试;替换/解关联阶段遇瞬时断网 → 单文件失败,需到结果页手动重试。
- **影响**:断网窗口出现在"替换"时,用户需人工介入。
- **建议**:为该阶段增加与上传一致的指数退避重试(2 次),失败再落 FAILED。
- **工作量**:约 0.5 人日。

### N4 明文 HTTP 收窄(HTTPS 支持)
- **背景**:当前全局 `usesCleartextTraffic=true` 放行局域网 HTTP(审阅时确认的简单方案)。
- **影响**:若服务端上 HTTPS,现状不收紧也安全;但公众场合抓包时明文可读。
- **建议**:改为 `networkSecurityConfig` 仅放行已配置的服务器域名/IP;如支持 HTTPS,直接走加密并默认 `cleartext=false`。
- **工作量**:约 0.3 人日。

### N5 大文件导入期间前台 Service 防杀
- **背景**:计划阶段风险项(风险 #2/#6);当前未实现前台 Service,极端省电策略可能杀进程。
- **影响**:100MB+ 文件长时间导入时,锁屏/后台可能中断。
- **建议**:导入进行中启动前台 Service + 通知(显示进度/取消),保证后台存活。
- **工作量**:约 1 人日。

### N6 remove-folder 删除整文件夹内容的风险提示
- **背景**:实测 `remove-folder` 会删除文件夹全部内容(purgeFolder),非仅空目录。
- **影响**:误操作会批量丢文档。
- **建议**:UI 二次确认文案明确"将删除该文件夹及全部文档";或对非空文件夹禁止删除。
- **工作量**:约 0.2 人日。

## 3. 体验与功能增强(可选)

### N7 深色模式 LIGHT 专项复测
- **背景**:FR-15 三选(SYSTEM/LIGHT/DARK)已实现;模拟器验证了"跟随系统 ↔ 深色"双向,浅色手动态未单列截图。
- **建议**:补一次 LIGHT 手动切浅色的回归记录。

### N8 chat 测试检索(FR-14)激活验证
- **背景**:功能已实现但默认关闭,未在端到端复测。
- **建议**:设置页开启 askForChatTest 后,验证导入完成 → query 工作区 → 返回 sources 的完整链路。

### N9 进度通知与 Widget 级状态
- **背景**:导入进度目前仅 App 内可见。
- **建议**:前台通知带进度/暂停/取消;可选桌面小组件显示最近导入结果(优先级低)。

### N10 日志导出格式增强
- **背景**:日志为 JSONL 单行结构,人工阅读性一般。
- **建议**:导出时可附一个易读摘要(按文件聚合的成功/失败统计),或导出 CSV 便于表格化。

### N11 多服务器/服务器档案管理
- **背景**:当前单服务器,改地址需重填。
- **建议**:设置页保存多套服务器档案(名称/地址/Key)并一键切换;导入前显示当前目标。

## 4. 工程红线(必须长期遵守)

| # | 红线 | 原因 |
|---|---|---|
| 1 | Kotlin 源码编辑禁用 PowerShell `Set-Content` | GBK 误读 UTF-8,曾致全文件 mojibake(BUG-006) |
| 2 | 统一 `ReadAllText/WriteAllText(UTF8 无 BOM)` 或 Read/Edit 工具 | 保证编码一致 |
| 3 | 批量删行用 Python 脚本**精确匹配** + 上下文校验 | 避免误删(BUG-007~012 教训) |
| 4 | domain 层禁放 Android 框架类 | JVM 可测性 |
| 5 | 网络 IO 测试用真实时间,不用 runTest 虚拟时间 | 避免测试挂起 |
| 6 | API 契约以真实实例实测为准,开发文档仅作初稿 | 服务端结构易漂移 |
| 7 | `keystore.properties` 口令与 `apikey.txt` 不提交、不外传 | 安全 |
