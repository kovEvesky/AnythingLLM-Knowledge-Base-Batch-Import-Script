## 1. 项目一句话

把 PC 版 AnythingLLM 文档批量导入工具(PowerShell `embed.ps1`)的功能**原样移植到 Android**(Kotlin + Jetpack Compose),用户用手机从本机存储选文件 → 批量上传到局域网 AnythingLLM 实例 → 触发嵌入并轮询验证,全程可视化、可重试、可审计。

## 7. 质量结论

- **功能完成度**:16/16 FR 落地,核心链路(选文件→预校验→选目标→上传→嵌入→验证→重试→日志)在模拟器全部走通并与 PC 版行为对齐。
- **稳定性**:79 单测覆盖文件名转换/预校验/错误分类/API 契约/重试/日志,零失败。
- **已知边界**(不影响交付,详见《07-下一步开发建议.md》):
  1. R11 真机回归未执行(无真机,维持模拟器交付底线);
  2. 替换阶段(update-embeddings deletes/remove-documents)无自动重试(FR-08 只要求上传重试);
  3. 全拒绝时"下一步"按钮未显式禁用(行为正确,体验可优化);
  4. 明文 HTTP 走全局 cleartext(局域网场景),HTTPS 支持未收窄;
  5. 大文件导入期间无前台 Service,极端省电策略可能杀进程。
