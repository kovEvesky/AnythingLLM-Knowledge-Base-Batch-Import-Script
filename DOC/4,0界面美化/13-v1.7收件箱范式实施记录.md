## 二、关键工程决策

1. **配置字段只加不改**:所有新字段(`defaultFolderName`/`lastMark*`/`silentReceive`/`hapticOnReceive`)在 `AppConfig` 带默认值,DataStore 老用户读旧文件时自然回退默认,无需迁移。
2. **"上次夹"独立写入**:`rememberLastMark()` 走单独的 DataStore edit,**不经过 `save()` 全量重建**,避免 UI 滑动过程中把设置页未提交的表单清掉。
3. **手势用 SwipeToDismissBox 但不真 dismiss**:`confirmValueChange` 里执行入箱逻辑后**返回 `false`**,条目靠状态从 PENDING→MARKED 后由 `refresh()` 从列表消失,视觉自动回弹。
4. **连续分拣**:`MarkEntrySheet` 确认后自动定位到下一条 pending,把"整理 N 条"从 N×5 次点击变成连续滑动。

## 三、踩坑记录(复用)

| 坑 | 现象 | 解法 |
|---|---|---|
| suspend 在普通 Thread 调用 | `ShareReceiver` 里 `configRepository.snapshot()` 编译报 "should be called only from a coroutine" | 用 `kotlinx.coroutines.runBlocking { }` 包一层 |
| `toConfig()` 全量重建覆盖 | 设置页 `save()` 重建整个 `AppConfig`,新字段若不回写会被重置成默认 | SettingsViewModel 加载/保存都带上 `lastMark*`,原样回写 |
| `animateItemPlacement` 是实验 API | 编译报 experimental | 文件头加 `@file:OptIn(ExperimentalFoundationApi::class)` |
| 中文 commit 在 Windows | PowerShell 直传 `-m` 可能乱码 | 用 `git commit -F <utf8文件>` |
| `VIBRATOR_SERVICE` deprecated | Android 12+ 建议 VibratorManager | 仅 deprecation warning,功能正常,暂不升级 |
| 资源文案必须资源化 | v1.4 规则:用户可见文字入 `strings.xml` | 新文案全部加 string 资源,未硬编码 |

## 五、遗留与下一步

1. **P1-1 双 Tab 收敛**:收集箱/知识库/资料库合并为"收件箱+库",需要把服务器同步与 FTP 同步在一个页分流,建议单独 PR 设计导航。
2. **P1-2 记住上次目标库**:即时导入向导(Select→Validate→Target→Import)预填上次目标。
3. **P1-3 按域名自动归类**:链接型条目按 host 规则自动入夹(Cubox 智能列表)。
4. **真机回归**:滑动手势的触发阈值/误触、震动效果、Toast 在 Android 13+ 的行为建议真机过一遍。
