## 4. 补充优化建议(NEW-01~06)

### NEW-01 通用单选列表组件(替代三处平铺)

- **背景**:MarkDialog(文件夹/工作区)、ArchiveDialog(资料库文件夹)、LibraryScreen MoveEntry 对话框(文件夹选择)三处均为 `forEach`+`RadioButton` 平铺,快照/目录项多时超高溢出(UI-02 只覆盖了第一处)。
- **建议**:抽 `ScrollableRadioList(items, selected, onSelect, heightIn=max 320.dp)` 组件,三处统一替换;文件夹带路径前缀显示(C-16 语义)保留为组件参数。
- **范围**:`ui/components/` 新建;不碰领域层。

### NEW-02 LibraryScreen 纳入 UI 改造范围

- **背景**:437 行,当前为 v1.3 功能性 UI,存在与主方案同类问题:ftpStatusIcon 纯文本符号、图标 contentDescription=null、FTP 横幅硬编码文案、同步按钮无阶段态、条目卡片无类型图标/同步状态徽标。
- **建议**:并入 P1/P2 改造——ftp 进度卡图标化(对齐 UI-11/12/25)、FTP 横幅入 strings.xml(UI-13)、同步按钮阶段化"空闲/连接中/同步中 x/y"(对齐 UI-21)、条目卡片加"已同步/未同步"徽标(对齐 UI-16)。
- **工时**:在原方案 P2 基础上 +0.5~1 人日。

### NEW-03 编译 deprecation 清理(4 处,顺手项)

| 位置 | 警告 | 处理 |
|---|---|---|
| `ShareReceiver.kt:75` | `extras.get(String)` deprecated | 改类型化读取(`getString`/`getParcelable`),注意保持 extractUris 的 Uri/List/Array 类型分发逻辑 |
| `HomeScreen.kt:61` | `LocalLifecycleOwner` 移至 lifecycle-runtime-compose | import 改 `androidx.lifecycle.compose.LocalLifecycleOwner` |
| `TargetScreen.kt:203` | `Modifier.menuAnchor()` deprecated | 换带 `MenuAnchorType` 的新重载 |
| `SettingsScreen.kt:399` | `Modifier.menuAnchor()` deprecated | 同上 |

- 建议在 P0 阶段一并清理(0.1 人日),保持编译输出干净。

### NEW-04 git 基线先行

- **现状**:`git status` 显示 v1.3 相关 10+ 个文件未提交(M:CHANGELOG/AnythingLLMApp/AppConfig/ConfigRepository/CollectScreen/CollectViewModel/HomeScreen/KnowledgeScreen/SettingsScreen 等),当前分支 main@3f31415 之后的工作未落库。
- **建议**:UI 改造**开工前**先确认并提交 v1.3 基线(需用户拍板 commit 与 message),避免 UI 改动与 v1.3 未提交改动混在一起难以回滚。

### NEW-05 方案参数更新(基线/回归/验证项)

- 单测基线:122 → **144**(新增 LibraryRepositoryTest 12 + FtpNamingTest 8 + FtpSyncEngineIntegrationTest 2)。
- 回归清单:方案 R12–R20 → **R12–R20 + F1–F6 + U1–U13 + C-16~19**。
- UI-06(LIGHT 模式)、UI-26(大字体)列入阶段 4 设备验证项;模拟器 AVD `anythingllm_api36` 现成可用。

### NEW-06 §4.4 目标气泡拖拽的 3 Tab 落地约束

- **布局**:气泡面板放收集箱 Tab 底部固定区(横向 LazyRow),需与"立即导入"快捷入口(顶部)和批量操作栏(底部)共存,建议批量操作栏保留、气泡面板作为第二层。
- **双语义投递**:拖拽目标需区分两类——① 服务器目标(文档文件夹/工作区,标记语义,MarkPlan)② 资料库文件夹(归档语义,LibraryRepository)。建议气泡按 Tab 上下文切换(收集箱显示服务器目标+资料库目标分区,或提供"标记/归档"切换)。
- **离线一致性**:目标来自本地快照/资料库,离线可用,与需求一"户外缓存结构快照"对齐——原方案此点不变。
- **工时**:维持 1–1.5 人日,但交互设计需先行确认双语义映射(建议列为待确认点 C-20)。

### 5.2 WSL 渠道可行性结论(已实证)

| 用途 | 结论 | 说明 |
|---|---|---|
| 源码/文本编辑、批量脚本处理 | ✅ **推荐** | UTF-8 环境规避 GBK mojibake;sed/python3 可用;PowerShell→WSL 传参一律"脚本文件 + wsl bash 执行"(转译截断实证:PowerShell 5.1 无 `&&`、引号会被吞) |
