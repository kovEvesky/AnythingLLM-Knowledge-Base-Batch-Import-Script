## 2. 发现的 BUG 与修复
### BUG-白灰同段崩溃(严重,已修复)
- 现象:分享新链接后进 Mark 页即崩溃 `Key "header_2131427615" was already used`(IllegalArgumentException)。
- 根因:白卡段(whiteSection)与灰卡段(graySection)各渲染同名「今天/更早」分组头,`sectionHeader` 的
  LazyColumn key = `"header_$stringResourceId"` 两段相同 → key 冲突。阶段 2 冒烟只有灰卡(白卡段空)未暴露;
  阶段 5 白卡+灰卡同日共存时必现。
- 修复:`sectionHeader` 增加 `prefix` 参数(白段 `white`、灰段默认 `h`),key 空间隔离。
- 验证:白卡(Example Domain 待整理)+ 灰卡(e2e 工作 / example.com 回收站)同日共存渲染正常。

### Sync 页状态文案误用(已修复)
- 现象:收藏夹条目全部为 MARKED 待同步时,聚合状态 EMBEDDING 显示「正在嵌入工作区」(误导,实际未运行)。
- 修复:EMBEDDING 文案 → 「待同步 N 项」。

## 3. 端到端验证(AnythingLLM 真实服务器)
环境:WSL2 `anythingllm` 容器(healthy,0.0.0.0:3001);模拟器经 10.0.2.2:3001 访问。
链路:
1. 分享 `https://example.com`(SEND intent)→ 静默接收(不拉起 UI)→ 条目 PENDING。
2. Mark 页右滑 → 归类气泡(工作/学习/积累/新建)→ 选「工作」→ 条目 MARKED。

   - 回收站条目(example.com)不入队;失败条目(e2e.example.com 域名不存在,服务器 500)显示「失败可重试」,重试按钮可用。
4. 标题自动抓取:分享 https://example.com 后条目标题 = "Example Domain"(v1.5 分享标题化,复测仍生效)。

## 4. 关键教训(Settings 保存语义)
- **Settings 测试连接使用表单临时值**(SettingsViewModel.testConnection → `s.apiKey.trim()`),仅点「测试连接」不持久化;
  DataStore 仍为旧配置。此时离开 Settings 去 Sync,引擎读到旧/空 Key → 401「API Key 无效」(实为无 Authorization 头)。
- **正确流程:改设置 → 点底部「保存并返回」→ 再同步**。测试连接成功 ≠ 已保存。
- 该语义为 v1.2 沿用设计(手动保存),非缺陷;文档记录以免误判为 bug。
