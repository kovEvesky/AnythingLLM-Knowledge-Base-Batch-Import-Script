## 一、方案定位(结论先行)

**一句话:把应用从「AnythingLLM 批量导入工具」重塑为「Mark To(mt)」——一个"分享即流式、滑一下即归类"的个人收藏流,配「收藏夹 → FTP / AnythingLLM 双通道同步」。**

| 维度 | v1.7 现状 | V1.9 目标 |
|---|---|---|
| 应用定位 | AnythingLLM 批量导入工具 | **Mark To(mt)** 个人收藏流 |
| Tab 结构 | 3 Tab:收集箱 / 知识库 / 资料库 | **4 Tab:Mark(M 图标)/ To(T 图标)/ Sync(循环箭头)/ Settings(齿轮)** |
| 分类体系 | 四类并存:资料库文件夹 / 知识库文件夹 / 知识库工作区(+旧默认夹) | **统一为"收藏夹"唯一分类体系**,每个收藏夹 = 本地缓存文件夹 + 服务器同名文件夹 + 同名工作区(**Q3 已确认**) |
| 整理手势 | 左滑=入默认箱,右滑=上次夹;标记后条目消失 | **白卡左滑=删除(进回收站),右滑=收藏夹气泡选择;标记后变灰沉底,灰卡再滑=撤销** |
| 排序 | 按日分组,标记即移走 | **流式:未标记在前(时间倒序),已标记在后(标记时间倒序)** |
| 卡片信息 | 标题 + 类型·来源·大小/URL | **时间 + 简要内容 + 来源 App(ClipDescription 尽力获取,未知兜底,Q2)** |
| 同步入口 | 知识库一键同步 + 资料库 FTP,两个独立 Tab | **单一同步 Tab,双子选项卡(FTP / AnythingLLM)统一编排(Q8:手动一键 + WiFi 自动开关)** |
| 收藏夹默认 | 无 | **预置:工作 / 学习 / 积累 / 回收站(回收站内置不可删)** |

**用户操作链路(理想态)**:分享 → 选 Mark To(静默收进)→ 打开 App 流式看今天收到什么 → 右滑弹气泡归入工作/学习/积累(或左滑删掉)→ 灰卡滑一下反悔 → 晚上一键同步,PC 目录与 AnythingLLM 知识库自动长成收藏夹结构。

## 三、数据模型与迁移方案

### 3.1 收藏夹模型 `FavoriteFolder`

```
FavoriteFolder(
    id: String,          // UUID
    name: String,        // 收藏夹名称
    color: Long,         // ARGB 色值(12 色调色板)
    builtin: Boolean,    // true=内置(回收站强制 true;工作/学习/积累 预置可删,见 Q11)
    sortOrder: Int,      // 长按拖动排序结果(Tab2)
    createdAt: String,
)
```

- **种子数据(Q1)**:预置 **工作 / 学习 / 积累 / 回收站** 四个收藏夹;回收站**内置不可删除**;工作/学习/积累 为预置示例夹(可删可改名,删除走迁移选择,见 Q5/Q11)。
- 存储:独立 JSON(`favorites.json`,参考 `LibraryRepository` java.io + kotlinx 方案,可单测)。

### 3.2 `CollectEntry` 扩展

| 字段 | 变化 | 用途 |
|---|---|---|
| `markFolder: String?` | → `markFolderId: String?`(收藏夹 id) | 标记目标改为收藏夹(Q3:唯一分类体系) |
| `markedAt: String?` | 新增 | 灰卡沉底排序 + 卡片展示 |
| `sourceApp: String?` | 新增 | 来源 App 显示(ClipDescription 尽力 + 未知兜底,Q2) |
| `EntryStatus` | 新增 `TRASHED` | 左滑删除 = 进回收站(灰卡、可撤销、**不参与同步,Q4**) |

- 灰卡判定:`status ∈ {MARKED, TRASHED, EXECUTING}`。
- 流式排序:未标记(PENDING)在前按 `collectedAt` 倒序;已标记/已删除在后按 `markedAt` 倒序。

### 3.3 分类体系统一(Q3)

- **收藏夹成为唯一分类体系**,替代原四类:资料库文件夹 / 知识库文件夹 / 知识库工作区。
- 每个收藏夹对应:
  1. **本地缓存文件夹**(**用户存储根目录 `MarkTo/{收藏夹名}/`**,Q10/Q11 定稿:默认建在手机用户储存根目录 MarkTo 文件夹,便于用户在文件管理器直接查找),分享文件副本缓存于此,链接暂存元数据;
  2. **服务器同名文件夹**:同步知识库时 `create-folder` ensure;
  3. **服务器同名工作区**:同步时 ensure;知识库中该文件夹内文档**默认全部嵌入同名工作区**。
- 注:写入用户存储根目录需处理 Android 10+ 分区存储(SAF 树授权或 `MANAGE_EXTERNAL_STORAGE`),作为阶段 1 工程要点。
- 简化效果:用户不再区分"标记到知识库还是资料库",收藏夹即分类,同步时双通道自动分流。

### 3.4 旧数据迁移(遗留 Q10)

- 旧已标记条目(带 `markFolder` 服务器文件夹名):推荐按文件夹名自动建同名收藏夹并归入;冲突归入"积累"。
- 旧本地资料库(`LibraryRepository`)数据、服务器端旧文件夹/工作区:**是否清除?待确认(Q10)** —— 推荐全部保留,不做删除,由用户手动清理。

## 四、Tab1 流式收件箱(核心交互)

### 4.1 页面结构

- 左上角 **"+" 按钮(Q7)**:弹出菜单 → 批量多选 / 即时导入向导 / 日志页。
- 流式列表:白卡(未标记)在前按接收时间倒序,灰卡(已标记/已回收)在后按标记时间倒序;顶部"今天/昨天/更早"轻量分隔。
- 卡片:相对时间 + 简要内容(链接=标题+域名、文件=文件名+大小、图片=缩略图+文件名)+ **来源 App 徽标** + 类型图标;`animateItemPlacement()` 回弹。

### 4.2 手势状态机

```
                 ┌────────────── 白卡(未标记,在前) ──────────────┐
                 │                                               │
     左滑(删除)  ▼                                               │ 右滑(归类)
   ┌─────────────────────┐                              ┌─────────────────────┐
   │ 进回收站收藏夹        │                              │ 底部弹收藏夹气泡      │
   │ 变灰+沉底+Snackbar   │                              │ 点选→归入,变灰+沉底  │
   └─────────────────────┘                              └─────────────────────┘
                 ▲                                               │
                 │           灰卡(已标记/已删除,在后)               │
                 └──── 左滑 或 右滑 = 撤销标记,恢复白卡回未标记区 ────┘
```

- **白卡左滑**(EndToStart)→ `TRASHED`:进回收站收藏夹,变灰沉底 + Snackbar"已移到回收站收藏夹"。
- **白卡右滑**(StartToEnd)→ 两段式:滑动完成后条目进入"待选"态(高亮),底部弹出**收藏夹气泡**(横向胶囊:名称+色点,常用置顶,**不含回收站**);点击 → 归入该夹,变灰沉底 + 提示"已归入[夹]"。**仅 1 个可归入用户夹 → 直接归入并提示"已存入默认收藏夹"(Q6)**;0 个 → 引导去 Tab2 新建。
- **灰卡左滑/右滑** → 撤销标记:恢复 `PENDING`,回未标记区按接收时间归位。
- **单击白卡/灰卡** → 弹气泡(归类/改夹);**气泡点空白取消 → 保持未标记(Q6)**。
- 批量多选保留为进阶能力:入口在左上角"+"(Q7)。

实现要点(复用 v1.7 经验):
1. `SwipeToDismissBox.confirmValueChange` 返回 `false` 不真 dismiss,靠状态刷新 + 回弹;
2. 右滑"待选→气泡"两段式:滑动完成不立即标记,气泡取消则保持未标记;
3. 灰卡双滑撤销注意滑动动画与状态刷新竞态,列表 key 稳定。

### 4.3 回收站(Q4)

- 回收站条目在流中为灰卡(可滑动撤销);Tab2 回收站收藏夹内可查看、可恢复(移回未标记或移入其它夹)、可彻底删除/清空;
- **回收站不参与 FTP / AnythingLLM 同步,仅参与标记与暂存文件**。

## 五、Tab2 收藏夹管理(全新,按 Q1 细化)

### 5.1 页面结构(Q1)

- **顶层:搜索框 + 加号**。加号 = 新建收藏夹(名称 + 12 色选择器 → 保存入列)。
- 内容:收藏夹卡片列表,**默认显示 工作 / 学习 / 积累 / 回收站**;卡片 = 色点 + 名称 + 条目计数,内置夹带锁定图标。

### 5.2 交互(Q1)

| 操作 | 行为 |
|---|---|
| **点加号** | 新建收藏夹(名称+12色)→ 保存 → 列表新增卡片 |
| **长按拖动** | 排序,松手落位(`sortOrder` 持久化;同时影响气泡与同步遍历顺序) |
| **左滑卡片** | 删除收藏夹 → 弹**迁移选择框(Q5)**:①迁移入其他收藏夹(选目标夹)②全部移入回收站 |
| **右滑卡片** | 重命名当前收藏夹(名称+颜色)→ 保存 |
| **点卡片** | 进入收藏夹详情:条目列表(时间+内容)→ 点条目可"移出(选夹)/ 彻底删除" |
| 回收站收藏夹 | 查看 / 清空(彻底删除文件副本) |

### 5.3 删除语义(Q5)

- 删除收藏夹时**由用户选择**条目去向:迁移入其他收藏夹 或 全部移入回收站(不做静默默认)。

## 六、Tab3 同步(单一入口,双子选项卡)

### 6.1 子选项卡 A:FTP → PC(Q3)

- 遍历收藏夹(**排除回收站**)→ PC 端建立**同名目录树** → 文件副本 + 链接 `.url`(复用 `FtpNaming`)。
- 复用 `FtpSyncEngine`:增量判定、2 次指数退避重试、失败保留可重试。
- 差异点:同步源从 `LibraryRepository` 切换为**收藏夹本地缓存文件夹**。

### 6.2 子选项卡 B:AnythingLLM(Q3)

对每个收藏夹(排除回收站):

1. **ensure 本地缓存文件夹**(`files/favorites/{name}/`);
2. **ensure 服务器同名文件夹**:`document/create-folder`(已存在跳过);
3. **ensure 服务器同名工作区**:`workspace/new`(已存在跳过,slug 化);
4. **文件条目**:上传至该文件夹 + **嵌入同名工作区**(`upload/{folder}` + `update-embeddings`,或直接 `workspace/{slug}/upload`);
5. **链接条目**:`upload-link` + `addToWorkspaces=[同名工作区]`。

**"知识库中用户文件夹内的资料默认全部嵌入同名工作区"**(Q3)即由 4/5 步保证。

**收藏夹改名/删除 → 服务器端不联动删除/重命名**(防误删,只同步新增与内容,提示用户手动清理)。

### 6.3 触发方式(Q8)

- 手动一键 + 可选 **"WiFi 下自动同步"开关**;同步状态/进度复用现有前台服务 + 通知。
