Mark To (mt) · V1.9 用户操作逻辑图
点击上方 Tab 查看对应页面的操作流程：方框 = 屏幕显示内容，箭头标签 = 用户操作。底部导航：Mark(M) / To(T) / Sync(循环箭头) / Settings(齿轮)。默认显示「Mark · 流式」。
打开 App / 分享后返回

→
流式列表
白卡(未标记)在前·时间倒序｜灰卡(已标记/已回收)在后·标记时间倒序｜顶部:今天/昨天/更早
▸ 白卡(未标记)操作
左滑 = 删除
灰卡·回收站收藏夹(沉底)+ Snackbar"已移到回收站收藏夹"
回收站不参与同步，仅标记与暂存(Q4)
右滑 = 归类
底部弹收藏夹气泡(工作/学习/积累/自定义·色点·常用置顶·不含回收站)
├ 点选某夹 → 灰卡·已归入 + 提示"已归入[夹]"
├ 仅1个用户夹 → 直接归入 + 提示"已存入默认收藏夹"(Q6)
└ 点空白取消 → 保持白卡未标记(Q6)
▸ 灰卡(已标记/已回收)操作
左滑 / 右滑 = 撤销标记
恢复白卡 → 回到未标记区(按接收时间归位)
单击卡片 = 归类 / 改夹
弹收藏夹气泡：白卡归类，灰卡改夹
▸ 左上角 "+"（Q7）
弹出菜单 → 批量多选 / 即时导入向导 / 日志页
打开 Tab2 → 收藏夹列表
顶部：搜索框 + 加号｜卡片：色点 + 名称 + 条目数
默认显示：工作 / 学习 / 积累 / 回收站（回收站带锁定图标）
点加号 = 新建收藏夹
输入名称 + 12 色选择器 → 保存 → 列表新增卡片
长按拖动 = 排序
松手落位 → sortOrder 持久化（同步影响气泡顺序与同步遍历顺序）
右滑卡片 = 重命名
编辑名称 + 颜色 → 保存
左滑卡片 = 删除收藏夹（Q5）
弹出迁移选择框（由用户选择条目去向）：
├ ① 迁移入其他收藏夹 → 选择目标夹 → 条目全部移入
└ ② 全部移入回收站
点卡片 = 进入收藏夹详情
条目列表（时间 + 内容 + 来源）
→
点条目 → 移出(选夹) / 彻底删除
→
回收站收藏夹 → 查看 / 清空（彻底删除文件副本）

[ FTP → PC ] ｜ [ AnythingLLM 本地知识库 ]
点"同步"
→
未配置? → 引导去设置页配置(Q2 扫码/手动)
→
已配置 → 连接校验 → 开始同步（前台服务 + 进度通知）
通道A · FTP → PC
遍历收藏夹(排除回收站) → PC 建立同名目录树
文件副本 + 链接 .url → 增量判定 / 失败重试 / 幂等覆盖
通道B · AnythingLLM 本地知识库
对每个收藏夹(排除回收站)：
① ensure 同名服务器文件夹
② ensure 同名工作区
③ 文件 → 上传文件夹 + 默认嵌入同名工作区(Q3)
④ 链接 → upload-link + 加入同名工作区
完成 → 回写 EXECUTED
同步完成
→
